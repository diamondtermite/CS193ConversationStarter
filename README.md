# CS193ConversationStarter
A conversation starter app that helps people find a topic of interest.
## MVP scope: 
  Ensure a working interface that gives the user options to
  1. Recieve a prompt for a conversation
  2. skip over a prompt
  3. rate prompt
## Once a working product is established:
  add filtering prompts given by topics of interest
  add reviewed weighted prompt system(better prompts occur more often)
  add saved prompts and account system to access the saved prompts

## Tech Stack:
- Java program for basic MVP
- Text file full of topics (String topicText, String topicInterestGroup)
- import IO libraries for java
- Github for version control
- VisualStudio code for IDE
- command line interface loop for MVP with possible website and gui for later purposes.
